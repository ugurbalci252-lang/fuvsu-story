# fuvsu-story
Fuvsu Pompa - Teknik Servis Instagram (@fuvsuofficall) günlük story görselleri. Otomatik üretilir.
Kurallar: müşteri adı, adres, telefon, plaka ASLA görsele/dosya adına girmez. Sadece ilçe + iş türü.

Görsel üretme: `node render.js story|post kart <konuIndex> cikti.jpg` veya `node render.js story|post foto <foto.jpg> cikti.jpg "<İş türü · İlçe>"`
